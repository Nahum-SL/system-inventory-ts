Flujo de trabajo

=================
Entorno development
=================
inicia el backend
``` bash
pnpm dev
```
inicia el frontend
``` bash
pnpm dev:frontend
```

=================
Entorno testing
=================
``` bash
pnpm test
pnpm test:watch
```

=================
Entorno production
=================
``` bash
pnpm build:all
pnpm start
pnpm smoke
pnpm dev:frontend
```
